# 👋 Bienvenido/a a mi GitHub

Soy Mateo, desarrollador orientado a Inteligencia Artificial, Análisis de Datos y Data Engineering, con formación en Big Data e IA y un enfoque totalmente práctico.

Este GitHub no es un recopilatorio de ejercicios: es un espacio donde documento proyectos reales, experimentos y soluciones que voy construyendo mientras aprendo y profundizo en el mundo de los datos y la IA.

La mayoría de mis repositorios están centrados en análisis de datos, machine learning y modelos de IA, trabajando con datasets reales, APIs públicas y flujos completos que van desde la obtención del dato hasta la interpretación de resultados. Me interesa especialmente entender el porqué de los datos, no solo entrenar modelos.

Además, mantengo un homelab activo, donde experimento con Docker, servicios autoalojados, automatización y despliegue de aplicaciones. Este entorno me permite unir la parte de IA y datos con la infraestructura, algo clave para llevar proyectos a producción y entender cómo funcionan más allá del código.

🔍 Qué encontrarás aquí:

Proyectos de Data Analysis y Machine Learning con Python

Experimentos con IA, LLMs y NLP

Pipelines de datos, APIs y bases de datos

Un repositorio dedicado a mi homelab, donde documento configuraciones reales y aprendizajes

🚀 Mi objetivo es seguir creciendo profesionalmente en el ámbito de IA, Data Science o Data Engineering, aportando soluciones prácticas y bien pensadas.

Si algo de lo que ves aquí te resulta interesante, siéntete libre de explorar los repositorios o contactarme.
